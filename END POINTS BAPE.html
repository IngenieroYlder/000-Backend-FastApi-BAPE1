Documentación de Endpoints BAPE

Guía rápida de consumo de API

Autenticación

POST /auth/login Iniciar Sesión

Obtener Token de Acceso (JWT).

Body (x-www-form-urlencoded): 
username: admin@bape.com
password: admin
POST /auth/register Registro

Registrar un nuevo usuario público.

JSON Body: 
{
  "email": "user@example.com",
  "password": "securePass",
  "first_name": "Nombre",
  "last_name": "Apellido",
  "phone": "3001234567"
}

Usuarios

GET /users/ Listar Usuarios
POST /users/ Crear Usuario
JSON Body: 
{
  "email": "nuevo@test.com",
  "password": "123",
  "first_name": "Juan",
  "last_name": "Perez",
  "phone": "3000000"
}
PUT /users/{id} Actualizar Usuario

Productos

GET /products/ Listar Productos
POST /products/ Crear Producto

  "name": "Camiseta",
  "price": 25.50,
  "stock": 10,
  "category_id": 1,
  "image": "http://img.com/a.jpg",
  "short_description": "Breve descripcion",
  "long_description": "HTML permitido",
  "gallery_images": ["http://img1.jpg", "http://img2.jpg"]
}
DELETE /products/{id} Eliminar Producto
